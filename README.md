# Black Jack Game 🎮 
This is the black jack game where you either win or loss by entering in the game again and again.This game is made by using python language.

***How to play***

To play this game you need to follow this steps:

First, clone or download the repository; 

Second, ensure you have Python installed; 

Third, open your terminal or command prompt and navigate to the project folder; 

Finally, run the command python game.py.
